# opening-hours.mbt 实施计划

> 本计划用于本仓库的逐项实施和验收。

**目标：** 交付原创 MoonBit OSM 营业时间表达式解析与求值库、CLI、网页演示和公开发布准备。

**架构：** 纯 MoonBit 核心包负责词法扫描、AST、日期/规则求值与注入日历；CLI 和 JS/Wasm 演示通过核心 API 调用。所有不支持语法返回包含源位置的错误。

**技术栈：** MoonBit CLI/compiler、MoonBit `moon test`、JavaScript/Wasm 后端、GitHub Actions。

---

## 第 1 周：词法分析与 AST

1. 初始化 MoonBit 模块、Apache-2.0、格式化配置和中文查重记录；运行 `moon check`。
2. 定义 `Date`、`DateTime`、`TimeRange`、`Rule`、`Expr`、带偏移的 `ParseError`。
3. 实现严格时间、星期缩写、关键字和分号规则扫描；非法输入返回错误而不崩溃。
4. 解析星期集合/范围和一个或多个时段；添加正反例单元测试。
5. 实现 `24/7`、`off`、`closed`，并记录不支持语法边界。

**验收：** `moon check` 与 `moon test` 通过；格式化检查通过。

## 第 2 周：求值器

6. 实现日期匹配、普通分号规则从左到右覆盖与关闭时段处理。
7. 实现 `is_open`、开放区间归一化和按日营业区间列表。
8. 实现 `next_change` 的边界搜索与属性式不变量测试（结果晚于输入，且两侧状态相反）。
9. 加入固定日期快照、周末、隔日、跨午夜和覆盖顺序测试。

**验收：** API 只依赖显式时间输入，固定快照和状态变化不变量测试通过。

## 第 3 周：日期和节假日

10. 支持月份范围、月日范围、跨年月日范围和有效日期校验。
11. 实现可注入 PH/SH 日历，且缺省空日历不会臆造节日。
12. 加入 2026 中国调休假期示例日历和政府来源说明；覆盖假期覆盖测试。
13. 收集不少于 50 条 OSM Wiki 原文示例作为来源明确的解析回归数据。

**验收：** 跨月/跨年、PH/SH、例子数据及回归集通过；示例来源可追溯。

## 第 4 周：发布面

14. 实现 CLI：表达式、固定日期时间、结果及下次变化。
15. 实现 JS/Wasm 构建入口和可交互静态网页演示。
16. 补齐中英 README、安装/API/CLI/语法范围/测试数量/查重结论/三个使用场景。
17. 配置 GitHub Actions 运行 `moon check`、`moon test`、`moon fmt --check`。
18. 整理至少 10 个有实际内容的中文提交，确认作者仅为 `wccerty`，创建公开仓库并推送。

**最终验收：** 本地 MoonBit 检查、测试、格式检查和 JS/Wasm 构建成功；仓库公开且提交历史不含其他作者、机器人作者或 Co-authored-by。
